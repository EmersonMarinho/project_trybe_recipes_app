Um aplicativo de receitas completo desenvolvido em React.js que permite explorar, gerenciar e preparar deliciosas receitas de comidas e bebidas. Integra duas APIs populares ([TheMealDB](https://www.themealdb.com/) e [TheCocktailDB](https://www.thecocktaildb.com/)) com funcionalidades modernas de favoritação e acompanhamento de progresso.

## ✨ Funcionalidades Principais

### 🔐 Autenticação
- **Login Simulado** com validação de:
  - Formato de e-mail válido (ex: `user@email.com`)
  - Senha com mínimo de 6 caracteres

### 🕵️ Busca Inteligente
- Pesquisa por:
  - Nome da receita
  - Primeira letra
  - Ingrediente principal
- Filtros por categoria (ex: Vegetariano, Massas, Sobremesas)

### 🧑🍳 Experiência de Cozinha
- Lista interativa de ingredientes com quantidades
- Vídeo tutorial integrado do YouTube
- Sistema de progresso com:
  - Marcação de passos concluídos ✅
  - Salvamento automático no `localStorage`

### ❤️ Personalização
- Favoritar receitas
- Perfil do usuário com:
  - Histórico de receitas concluídas
  - Receitas favoritas organizadas por categoria
